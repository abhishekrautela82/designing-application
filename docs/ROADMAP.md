# Roadmap (Android-first)

## Phase 1 — MVP (8–12 weeks)
- Auth + Projects
- Capture/upload + storage
- 2D editor:
  - segmentation for core surfaces
  - paint/material replacement
  - basic object placement
  - lighting presets (simple)
- Versions + snippets
- Exports (standard)

## Phase 2 — Pro (8–12 weeks)
- Scale calibration + measurement support
- Better masks + refinement tools
- Shadow grounding + improved relight
- Asset library (favorites/recents)
- Materials list export

## Phase 3 — Best-in-class Hybrid (12–20 weeks)
- Guided multi-photo capture
- Scene reconstruction for limited viewpoint changes
- 3D mode with Filament + ARCore
- Cloud high-quality render exports
- Subscription/paywall + usage limits

## Phase 4 — Growth
- Collaboration (share projects)
- Brand partnerships/catalog
- iOS version (later)
